# Guía de estudio · Tipos y ciclo de vida del dato

Página web interactiva para estudiar los 10 temas de la asignatura *Tipos y ciclo de vida del dato*:

1. La estadística
2. Tipos de datos estadísticos
3. Ciclo de vida de los datos
4. Etapas iniciales del ciclo
5. Recolección de datos
6. Limpieza del dato
7. Análisis de datos, interpretación y valoración de resultados
8. Almacén del dato (data warehouse)
9. Disponibilidad del dato
10. Aspectos normativos

Incluye diagramas, ejemplos reales, calculadoras interactivas (muestreo, boxplot/IQR, correlación), un test de autoevaluación por tema y un glosario.

Abre `index.html` en el navegador o visita la versión publicada con GitHub Pages.
